# 📘 बैकएंड इंजीनियर के लिए कंप्यूटर नेटवर्क्स: त्वरित सारांश

> **उद्देश्य:** क्लाइंट-सर्वर कम्युनिकेशन, डेटा पैकेट फ्लो और इंटरनेट के कार्यप्रणाली को समझना, जो किसी भी बैकएंड डेवलपर के लिए अनिवार्य है।

## 🌐 अध्याय 1: नेटवर्क क्या होता है?

| कांसेप्ट | परिभाषा |
| :--- | :--- |
| **नेटवर्क** | दो या दो से अधिक डिवाइस का आपस में जुड़कर डेटा और रिसोर्स शेयर करना। |
| **उद्देश्य** | डेटा ट्रांसफर, रिसोर्स शेयरिंग (जैसे प्रिंटर), और कम्युनिकेशन। |

### **💡 नेटवर्क के प्रकार (Types of Networks)**

| नाम | पूरा नाम | क्षेत्र |
| :--- | :--- | :--- |
| **PAN** | Personal Area Network | बहुत छोटा (Bluetooth, Hotspot) |
| **LAN** | Local Area Network | ऑफिस या बिल्डिंग तक (कॉलेज लैब) |
| **MAN** | Metropolitan Area Network | शहर के स्तर तक (केबल नेटवर्क) |
| **WAN** | Wide Area Network | बहुत बड़ा (देश/दुनिया) |
| **इंटरनेट** | WAN का एक विशाल नेटवर्क | **WAN**s का मिला-जुला रूप। |

---

## ⚙️ अध्याय 2: नेटवर्क कैसे काम करता है? (वेबसाइट रिक्वेस्ट)

1.  **DNS (Domain Name System):** डोमेन नाम (`google.com`) को **IP Address** (नंबर) में बदलना।
2.  **Client Request:** ब्राउज़र, HTTP रिक्वेस्ट के माध्यम से सर्वर से पेज मांगता है।
3.  **Server Response:** सर्वर, HTML, CSS, JS फ़ाइलों के साथ HTTP रिस्पॉन्स भेजता है।
4.  **Browser Render:** ब्राउज़र फाइलों को पढ़कर वेबसाइट प्रदर्शित करता है।

## 📦 अध्याय 3: OSI मॉडल (7 लेयर्स)

यह नेटवर्क कम्युनिकेशन का आधार है। (याद रखने का ट्रिक: **P**lease **D**o **N**ot **T**hrow **S**ausage **P**izza **A**way)

| लेयर | नाम | मुख्य कार्य | प्रोटोकॉल / डिवाइस |
| :--- | :--- | :--- | :--- |
| 7 | **Application Layer** | यूजर से इंटरैक्ट करना | HTTP, HTTPS, FTP |
| 6 | **Presentation Layer** | डेटा को **Encrypt/Decrypt** करना | SSL, TLS |
| 5 | **Session Layer** | कम्युनिकेशन सेशन संभालना (लॉगिन ट्रैकिंग) | Sockets |
| 4 | **Transport Layer** | डेटा को छोटे टुकड़ों (Segments) में तोड़ना; विश्वसनीयता | **TCP, UDP** |
| 3 | **Network Layer** | **रूट** तय करना (IP Address) | **IP**, Router |
| 2 | **Data Link Layer** | डेटा को फ्रेम बनाना; **MAC Address** देखना | Ethernet |
| 1 | **Physical Layer** | असली ट्रांसमिशन (केबल, सिग्नल) | RJ45, Fiber |

---

## 🧭 अध्याय 4: TCP vs UDP (Transport Layer Protocols)

| बिंदु | TCP (Transmission Control Protocol) | UDP (User Datagram Protocol) |
| :--- | :--- | :--- |
| **भरोसेमंद (Reliable)?** | **हाँ ✅** (त्रुटि सुधार और गारंटीड डिलीवरी) | **नहीं ❌** (कोई गारंटी नहीं) |
| **Connection** | Connection-oriented (हैंडशेक आवश्यक) | Connectionless |
| **स्पीड** | धीमा (ओवरहेड के कारण) | **तेज़** |
| **उपयोग** | HTTP, HTTPS, FTP, Email (डेटा लॉस नहीं चाहिए) | Video Streaming, Gaming, DNS (स्पीड ज़्यादा ज़रूरी) |

---

## 🧱 अध्याय 5: IP Address & Routing

* **IP Address:** नेटवर्क में हर डिवाइस का **Unique Address** (जैसे घर का पता)।
    * **IPv4:** `192.168.0.1` (32-bit)
    * **IPv6:** `2001:db8::1` (128-bit, नया वर्ज़न)
* **Routing:** डेटा को **Router** की मदद से सही रास्ते से गंतव्य (destination) तक पहुंचाना।

### **HTTP & HTTPS (Application Layer)**
* **HTTP (Port 80):** क्लाइंट और सर्वर के बीच डेटा भेजने का **असुरक्षित** नियम।
* **HTTPS (Port 443):** HTTP + **SSL/TLS Security Layer**। डेटा **encrypt** होता है, जिससे यह सुरक्षित बन जाता है।

## ⚡ अध्याय 6: लोड बैलेंसर, CDN और सुरक्षा

| कांसेप्ट | कार्य | बैकएंड महत्व |
| :--- | :--- | :--- |
| **Load Balancer** | मल्टीपल सर्वर के बीच ट्रैफिक को समान रूप से वितरित करना। | सर्वर ओवरलोडिंग रोकना, उच्च उपलब्धता (High Availability) सुनिश्चित करना। |
| **CDN (Content Delivery Network)** | वेबसाइट की **Static फ़ाइलें** (Images, JS, CSS) को उपयोगकर्ता के सबसे पास के सर्वर से भेजना। | वेबसाइट की स्पीड बढ़ाना और सर्वर लोड कम करना। |
| **Firewall** | अनधिकृत एक्सेस (Unauthorized access) को रोकने के लिए ट्रैफिक को मॉनिटर और कंट्रोल करना। | नेटवर्क की पहली सुरक्षा दीवार। |
| **Encryption** | डेटा को सुरक्षित रखना (encode करना)। | HTTPS, पासवर्ड स्टोर करना। |
| **Authentication** | उपयोगकर्ता की **पहचान** सत्यापित करना। | लॉगिन मैकेनिज्म। |
| **Authorization** | उपयोगकर्ता को रिसोर्स तक **पहुँच** देना या रोकना। | API एक्सेस कंट्रोल। |

## 🌍 अध्याय 7: बैकएंड इंजीनियर को क्या सीखना चाहिए? (सारांश)

1.  **API Structure:** रिक्वेस्ट (`GET /users`) और रिस्पॉन्स (`200 OK`) को समझना।
2.  **Security Focus:** HTTPS और SSL/TLS क्यों अनिवार्य हैं।
3.  **Scalability:** Load Balancer और CDN का उपयोग कब और कैसे करना है।
4.  **OS Interaction:** Firewall और Ports का क्या कार्य है।
5.  **Protocol Choice:** TCP vs UDP का सही इस्तेमाल (विश्वसनीयता बनाम गति)।
